# M0 — Scaffold and guardrails: handoff

Branch `m0-scaffold`. Session date 2026-11-21.

## What was built

- **Pack installed.** The pack's `CLAUDE.md` replaced the root `CLAUDE.md` and `AGENTS.md`. Both
  stay gitignored, as Tagir set them. `docs/` and `src/content/data/{tuning.json, ch1/, ui/}`
  were copied in; the content is byte-identical to the pack.
- **Dependencies** (approved by the brief): `three@0.187.0`, `@types/three@0.187.0`,
  `@playwright/test@1.65.1`, pinned exactly. Nothing else.
- **Removed:** the scaffold's mulberry32 `prng.ts`, the demo `step.ts`/`replay.ts`/`types.ts` and
  their golden test, the worker's fixed-step loop, the WebGL2 placeholder (`render/canvas.ts`), the
  palette content kind that only it used, and `ui/Overlay.tsx`.
- **Numbers** (`03` §1): `src/sim/rng.ts`, `math.ts` (`mulPm`, `clamp`, `isqrt`, `softmax`,
  `sample`), `hash.ts`, and `exp-table.ts`, generated by `scripts/gen-exp-table.ts`
  (`npm run gen:exp-table`) and committed.
- **Bridge:** `protocol.ts` matches `02` §3 verbatim. The worker answers `init` with `ready` and
  everything else with `error: "not implemented"`, and runs no timer. `client.ts` is a typed
  request/response client that drops stale replies.
- **Content:** `schemas/tuning.ts` is a strict Zod schema for `tuning.json`. **Every knob has a
  `.describe()` text**, which is the single documentation of the knobs. `load.ts` collects every
  problem into one `ContentError`, naming the key path and the bad value. `npm run content:check`
  checks tuning and the ui text (en/ru key parity). `ch1/` is skipped until M1, as the brief says.
- **i18n:** `src/i18n/t.ts` (`addTables`, `setLocale`, `t(key, params?)`). A missing key returns
  `⟦key⟧` and warns once.
- **Shell:** a top bar with the town name and an EN/RU switch, an empty world area, and a content
  error screen. Interface keys were added in both languages: `ui.language`, `ui.locale.*`,
  `ui.error.title`.
- **Debug list, brought forward from M8 at Tagir's request:** `?debug=1` or the backquote key shows
  every tuning key, its value and its description, read from the schema. Read-only until M8.
- **ESLint:** the `02` §2 import table is data in `eslint.config.js`. The determinism bans
  (including `Math.exp/log/sqrt/pow`) cover `src/sim` and `src/player`. `postMessage` is banned
  outside `src/bridge`. Fixtures in `tests/lint-fixtures/` are linted by `tests/lint.test.ts`.
- **Scripts** from the `CLAUDE.md` table. `sim`, `balance`, `calibrate` and `golden:update` print
  "not available until …". `build` prints the gzipped JS size and fails above 400 kB.
- **Playwright:** the smoke test runs against the production build served under
  `/some/sub/path/`.
- **CI:** `.github/workflows/ci.yml`, with the Pages deploy and the itch.io steps commented out,
  plus a note for Tagir.
- `README.md` for humans.

## Deviations from the spec

- **The debug list exists from M0** (`02` §6 and the pack put the debug panel in M8). Tagir asked
  for every testable number to be visible in the dev UI now. It is read-only and only lists
  tuning.
- **Text schema:** `src/content/schemas/index.ts` holds `TextSchema` for both `ui/` and
  `ch1/text/`, instead of a separate `ui.ts`.
- **Vitest from Git Bash:** on this machine, running vitest from a shell whose working directory
  has a lowercase drive letter (`c:\www\vkbv`) loads vitest twice and fails with "failed to find
  the current suite". Run npm commands from PowerShell or a `C:\` path. This is an environment
  issue, not a project issue.
