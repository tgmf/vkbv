## Deviations and notes

- **`npm run check` once per batch.** It ran once over all of Phase A's changes, which were then committed
  in five parts; the same for Phase B. It did not run before each of those commits.
- **B5's "at rain start"** is read at the end of the first fog step that sees the rain. `roadBlocked` can
  only be set when `roadworks_day` reacts to the rain, and the fog steps when the lantern passes a boundary.
- **Seeds are vetted live** for goldens and balance, as `?seed=` would. At first that was at `vetting.fog`'s
  coarse knobs, which M4-1 showed is not the world played; it now runs at the game's own knobs (After review).
- **`CLAUDE.md` is ignored by git.** Its command table was updated locally for `npm run check` (quick
  calibration) and `npm run balance` (time), but that change is not in any commit.
- **`--todos`:** two writer markers remain, `sl.rokko_morning.sails` in `ch1/text/en.json` and `ru.json`.
  The UI texts have none.
- **`--actions`:** every cat can show its listed activities and the built-ins, and the five card interrupts
  that reach any cat (`groom`, `look_at_glint`, `shake_paw`, `startle`, `stretch`). Marti can also show
  `blow_whistle`, `pick_up` and `sit_in_box`; the crew can show `tea_break` and `work_road`.

## Open fog issues (carried, none closed)

- **M2-24** (a storylet's exit reading its own onEnter flag): M4 does not depend on it; no Chapter 1
  storylet does this.
- **M2-25** (fogged walkers and closing edges): bears on Chapter 1's only closing edge, `roadworks_pass`,
  which fogged cats may cross after the road is blocked. Not traced in M4; B5 reads the road before anyone
  could cross it.
- **M2-13** (the tiny world's stochastic cat): no effect on M4.
- **The pace gap:** it is every B9 miss above, and it moves B5 and B6. The fog under-predicts a blocked road
  by 10–15 points (M4-3's reference comparison), so B5's means are low. In B6 the road's state
  decides which of `blocked_road` and `usual_route` Marti meets.
- **The race storylet's work overshoot, the state floor:** part of the same road error. The state floor
  is why 3000/3 calibrates worse.
