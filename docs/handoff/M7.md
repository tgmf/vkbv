## Fixed while checking

- **The controller started as if a day were playing.** In the half second before the worker answered `init`,
  the frame loop took the empty first player for a game in progress: `watch` showed again after every reload
  (the playthrough's hint record caught it), and the empty player could have been saved over the real save.
  The controller now starts in `preparing`, not ready, until a day starts.
- **The teaser scene during "preparing" reported tick 0,** so the dev-page tests pressed Space before the day
  had started. The teaser is drawn only while it plays; while preparing nothing new is drawn (its last image
  stays under the line).
- **The hint's class name `hint` was already the cards' target line** ("on a cat · on a thing"): the new style
  turned each into a floating box over the card names. Renamed `hint-line`.
- **The teaser's line covered the boat;** it moved to the top of the view, and the two cats stand further
  apart.
- **The backquote** reached the teaser's "any key skips" first; the debug panel opens at any time again.

## Deviations and notes

- **`npm run e2e` at its default parallelism (10 workers here) fails on load,** not on M7: 8 tests timed out
  waiting for playback (1 tick/s instead of 16) while the first playthrough also ran. With 4 workers only
  `frame-time` failed; with 3 workers (and `frame-time` alone) everything passed. The per-page cost is the same
  as M6's (above), and `frame-time` alone gives M6's numbers. The first playthrough adds 8–14 minutes of a
  page that vets live and plays the day five times. Suggest running the browser suite with `--workers=3`, or
  setting `workers` in `playwright.config.ts`; not changed without you.
- **Tests open seeds as a player would:** the M6 tests now open `?seed=4` and skip the teaser; a seed on the
  offline list starts at once (vetting it would give itself).
- **The first playthrough inspects by keyboard focus and Enter** (`06` §8): a click on an object at 06:40 on
  this seed hit Marti's marker drawn over it.
- **What seed 1 does** (M3-3, M3-4): the morning cards on the roadworks change nothing there, and the unprimed
  lure brings Marti out, so there is no "turns back, prime him" step; `notready` and `morning` never show on
  this seed.
- **Assist mode** is a setting with no highlights behind it (M7-1). Tagir described it on 2026-11-26 (`06` §2); when to build it and five details are open in M7-1.
- **The end screen's line** is the writer marker `ui.end.line` in `ch1/text` (your answer).
- **Not committed by me, not mine:** Prettier finds unformatted files from earlier milestones
  (`tests/budget/*`, `tests/fixtures/tiny/*`, `tests/sim/fog-pins.test.ts`, …); `npm run check` does not run
  Prettier. Left as they are.
- **Still in `05` §5.2:** the sentence cut off at line 183 (reported in M6).
- **Out of the brief, not built:** telemetry (including `hint_shown`), the debug panel's tabs, sound volume.
